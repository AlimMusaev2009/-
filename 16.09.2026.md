Тема
Формирование сущностей таблиц для реляционных баз данных.

**Выбранный музей:** Государственный Эрмитаж (г. Санкт-Петербург)

## Список сущностей и их внешних ключей (FK)

1. **`Exhibits` (Экспонаты)**
   * **Описание:** Основная единица хранения. Содержит информацию о названии, годе создания, материалах, размерах, текущем состоянии.
   * **FK:** `artist_id` (ссылка на `Artists`), `collection_id` (ссылка на `Collections`), `location_id` (ссылка на `Locations`), `category_id` (ссылка на `Categories`).

2. **`Artists` (Художники/Авторы)**
   * **Описание:** Справочник авторов произведений. ФИО, годы жизни, страна, биография.
   * **FK:** Нет (справочник).

3. **`Collections` (Коллекции/Фонды)**
   * **Описание:** Группировка экспонатов по происхождению или тематике (например, «Итальянская живопись», «Нумизматика», «Античность»).
   * **FK:** `curator_id` (ссылка на `Employees` — хранитель коллекции).

4. **`Locations` (Локации/Помещения)**
   * **Описание:** Физическое местоположение экспоната. Залы, этажи, витрины, запасники.
   * **FK:** `building_id` (ссылка на `Buildings`), `parent_location_id` (ссылка на саму себя для иерархии: Зал -> Витрина -> Полка).

5. **`Buildings` (Здания/Корпуса)**
   * **Описание:** Информация о зданиях музейного комплекса (Зимний дворец, Главный штаб и т.д.).
   * **FK:** Нет.

6. **`Employees` (Сотрудники)**
   * **Описание:** Персонал музея. Директора, хранители, экскурсоводы, смотрители, реставраторы.
   * **FK:** `position_id` (ссылка на `Positions`), `department_id` (ссылка на `Departments`).

7. **`Positions` (Должности)**
   * **Описание:** Справочник должностей (Хранитель, Экскурсовод, Реставратор).
   * **FK:** Нет.

8. **`Departments` (Отделы/Департаменты)**
   * **Описание:** Структурные подразделения музея (Отдел античного мира, Отдел реставрации, Экскурсионный отдел).
   * **FK:** `head_id` (ссылка на `Employees` — начальник отдела).

9. **`Exhibitions` (Выставки/Экспозиции)**
   * **Описание:** Временные или постоянные выставки. Название, дата начала, дата окончания, тема.
   * **FK:** `curator_id` (ссылка на `Employees`).

10. **`Exhibition_Exhibits` (Связь Выставки-Экспонаты)**
    * **Описание:** Таблица для реализации связи "Многие-ко-многим". Один экспонат может участвовать в разных выставках, на одной выставке много экспонатов.
    * **FK:** `exhibition_id` (ссылка на `Exhibitions`), `exhibit_id` (ссылка на `Exhibits`).

11. **`Tickets` (Билеты)**
    * **Описание:** Информация о проданных билетах. Тип (взрослый, льготный), дата посещения, цена.
    * **FK:** `visitor_id` (ссылка на `Visitors`), `exhibition_id` (если билет на конкретную выставку).

12. **`Visitors` (Посетители)**
    * **Описание:** Информация о посетителях (для системы лояльности или статистики). ФИО, контакты.
    * **FK:** Нет.

13. **`Restoration_Log` (Журнал реставрации)**
    * **Описание:** История реставрационных работ. Дата, описание работ, результат.
    * **FK:** `exhibit_id` (ссылка на `Exhibits`), `restorer_id` (ссылка на `Employees`).

14. **`Storage_Conditions` (Условия хранения)**
    * **Описание:** Требования к температуре, влажности для определенных типов экспонатов.
    * **FK:** `category_id` (ссылка на `Categories`).

15. **`Categories` (Категории)**
    * **Описание:** Тип экспоната (Живопись, Скульптура, Графика, Оружие, Мебель).
    * **FK:** Нет.
